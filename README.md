# 💍 Wedding Guest Table Lookup

A simple and interactive web application that helps wedding guests find their assigned table by searching their names.

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

</div>

## ✨ Features

- Search guests by name with autocomplete suggestions.
- Reveal assigned table numbers instantly.
- View other guests assigned to the same table.
- Wedding-themed design with animated decorations.
- Responsive user interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/sapuCodes/wedding-guest-table-lookup.git
   ```

2. Open the project folder.
3. Run `index.html` in your web browser.
